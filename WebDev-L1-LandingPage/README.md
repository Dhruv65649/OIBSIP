# NovaTech Landing Page

## Internship Task 1 - Landing Page

A responsive static landing page created using HTML5 and CSS3.

### Technologies
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Media Queries

### Features
- Sticky navigation bar
- Hero section with call-to-action
- Features section
- About section
- Client testimonial
- Contact and social links
- Responsive mobile layout
- Hover effects
- Consistent color palette

### How to Run

1. Extract the ZIP file.
2. Open the `novatech-landing-page` folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click `index.html` and choose **Open with Live Server** if the Live Server extension is installed.
5. Alternatively, double-click `index.html` to open it directly in your browser.
